- [x] 3.1 实现 `POST /api/v1/messages` 的请求模型与字段校验（source/title 必填，level 限 info|warning|error，need_ack 默认 false，occurred_at 默认服务接收时间），验证：合法请求返回 202 与 message_id
- [x] 3.2 实现校验失败响应：返回 422 并指明出错字段，且不创建消息记录，验证：缺 source、level=critical、字段类型错误三种用例各返回 422 且数据库中记录数不变
